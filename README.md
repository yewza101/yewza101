## Research

| Project | Description |
|---|---|
| [**BVCRSA**](#) | Blockchain-verified conjunctive range search over encrypted IIoT data. Threshold EC-ElGamal with aggregate-then-decrypt cuts client decryption calls from O(\|S<sub>Q</sub>\|) down to O(1). |
| [**PLOSHA-RMFR**](#) | TEE-assisted secure aggregation for edge–fog IIoT. Predictive load-sharing with multi-layer fault recovery, computation sealed inside SGX enclaves. |
| [**ACB-SRCAT**](#) | A self-optimizing encrypted search index that splits and merges hotspots in real time, with context-bound tags that block cross-query linkage. |
| [**ZK-Redact**](#) | Zero-knowledge authorized redaction for permissioned blockchains — sharded batch ZKP verification and a Merkle-authenticated provenance audit index. |
| [**VeRedact-PQ**](#) | Post-quantum redactable blockchain for GDPR compliance. Subject-controlled, field-scoped redaction enforced by threshold MPC and chameleon hashes. |
